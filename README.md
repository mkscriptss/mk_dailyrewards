# MK Daily Rewards

Daily login rewards with normal and VIP tracks, streaks, VIP codes, Tebex VIP, live admin panel and four layouts

**Latest version:** `1.0.1` · [Changelog](CHANGELOG.md) · [Releases](https://github.com/mkscriptss/mk_dailyrewards/releases)

## Where to get it

MK Daily Rewards is a paid FiveM resource by **MK Scripts**, delivered through the Cfx.re Asset Escrow.
Buyers download every update from [portal.cfx.re](https://portal.cfx.re) → Granted Assets.

## Update check

This repository holds the release history only – no source code. When the resource starts, the server console
tells you if a newer version is published here (turn it off with `set mk_versioncheck false` in server.cfg):

```
[mk_dailyrewards] update available: v1.0.0 -> v1.0.1 https://github.com/mkscriptss/mk_dailyrewards/releases/tag/v1.0.1
```
